# متجر عناية بالبشرة — قالب عربي RTL

قالب متجر ثابت (HTML/CSS/JS بدون أي مكتبات) بنفس بنية متاجر التجميل العراقية:

- شريط إعلانات متحرك + هيدر ثابت (قائمة، شعار، بحث، سلة)
- بانر رئيسي
- أقسام منتجات بشكل كاروسيل بخلفيات ملونة (عروض، موسمية، الأكثر طلباً، عطور، مكياج)
- تصنيفات دائرية «اختاري روتينج» + «تسوقي حسب نوع بشرتج»
- بانرات، مقالات، فوتر مع نشرة بريدية
- شريط سفلي للموبايل + زر واتساب عائم
- سلة تسوق (محفوظة في المتصفح) مع شريط التوصيل المجاني وإتمام الطلب عبر واتساب

## التعديل

كل المحتوى في ملف واحد: **`data.js`**

- `STORE` — اسم المتجر، الشعار، رقم الواتساب، القوائم، البانرات، المقالات
- `SECTIONS` — أقسام الصفحة الرئيسية وترتيبها
- `PRODUCTS` — المنتجات (الاسم، السعر، السعر القديم، الصورة، القسم)

ضع الصور في مجلد `images/` واكتب مسارها في `img`. الألوان في أول `style.css` داخل `:root`.

## التشغيل

افتح `index.html` مباشرة، أو انشره على GitHub Pages / Vercel.
